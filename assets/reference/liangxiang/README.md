# 良乡首版关卡参考库

本目录已经从校园广泛采集库收缩为首版实现参考。当前只服务两个目的：

1. 为第一关“北湖动物借道”提供北湖、红桥、湖岸、树列和动物区域的外观与局部空间证据；
2. 为第二关“北理桥校园网掉线”提供北区／南区分隔和章节过渡的整体地图依据。

从 [`INDEX.md`](INDEX.md) 开始。空间边界见 [`spatial-structure.md`](spatial-structure.md)，来源和复用限制见 [`source-manifest.md`](source-manifest.md)。不要批量打开整个照片目录。

```text
liangxiang/
├── core-areas/north-lake-greenery/  北湖原始参考
├── maps/                            校园总图和北湖裁切
├── derived/                         项目整理的结构草图
├── previews/                        两张快速联系表
├── INDEX.md                         当前强制入口
├── spatial-structure.md             首版关卡空间边界
├── spatial-topology.csv             简化关系表
└── source-manifest.md               来源与复用限制
```

所有内容只供设计研究。正式美术必须进入 `assets/game/`。
