# 北京理工大学良乡校区视觉与空间参考库

更新日期：2026-09-03

本目录保存为二维横向双人游戏搜集的良乡校区参考材料。它不是“校园美图相册”：地图负责确认区域与相邻关系，同框照片和连续路线负责确认局部连接，单张照片只负责建筑轮廓、材质、色彩、尺度和生活气氛。

正式设计前先读 [`spatial-structure.md`](spatial-structure.md)。校园总结构工作图见 [`derived/campus-structure-working-map.png`](derived/campus-structure-working-map.png)，白桥亭廊、北湖红桥、生态岛、动物区和思源榭的局部结构见 [`derived/north-lake-working-topology.png`](derived/north-lake-working-topology.png)。

## 当前库存

- 原始或来源级视觉参考 216 个：4 张本地地图图像、24 张较早校方照片、13 张第三方旧参考、153 张 2023—2026 年材料、22 张近期视频封面；
- 20 张联系表，用于快速浏览不同主题和“空间桥”；
- 2 张派生结构图 PNG 及其 2 份可编辑 SVG；
- 2 份完整来源 PDF：较新校方平面图与 2025 年良乡校区暑校学生体验报告；
- 整个目录共 247 个文件，约 218 MB，其中图片 238 张。

统计数量只说明搜集覆盖面，不等于其中每张图片都能进入游戏。大部分照片和视频没有开放复用许可，当前用途是内部研究和原创重绘。

## 先看哪几份文件

1. [`spatial-structure.md`](spatial-structure.md)：已确认的校园骨架、北湖局部关系、证据强弱、关卡转译规则和待核对事项。
2. [`spatial-topology.csv`](spatial-topology.csv)：地点关系的机器可读表；后续可由 MATLAB `readtable` 读取，也便于检查关卡有没有跨区乱接。
3. [`contact-sheet-spatial-bridges-2023-2026.jpg`](contact-sheet-spatial-bridges-2023-2026.jpg)：同时含有多个地标或完整过渡空间的高价值照片。
4. [`source-manifest.md`](source-manifest.md)：每组文件的来源、日期、来源性质和当前允许用途。
5. [`video-index.md`](video-index.md)：把可用于核对路径的视频和只适合观察气氛的视频分开。

## 证据分级

### A 级：确定整体方位和组团

- `maps/liangxiang-campus-map-2022.png`：校方标注导览图，包含北区、南区、步行路径和时间。
- `maps/liangxiang-campus-map-current.pdf` 及同名 PNG：校方较新平面图；另保存北湖和文体—国防文化组团两张裁切图，便于核对局部标签。
- `recent-2023-2026/student-maintained-maps/`：2024—2025 年学生维护地图及文萃楼群内部图。
- `recent-2023-2026/qinyuan-student-2026-09-02/2026-qinyuan-09-plan-from-jinggong-xiaolaba.jpg`：图中标注更新日期为 2026-08-19，补充勤园和近期建设状态。

地图用于回答“谁在谁的哪边”和“是否跨区”，不用于精确测距。

### B 级：确定局部邻接和连续路线

- `recent-2023-2026/campus-updates-2025/` 中的北湖与文体—国防文化区域航拍；
- `recent-2023-2026/international-student-2025-2026/` 中体育馆与国防文化广场的地面同框照片；
- `recent-2023-2026/exchange-student-2024-2026/` 中北湖白桥—亭廊、北湖红桥—对岸建筑、普通校园道路和礼堂柱廊轴线；
- `recent-2023-2026/visitor-photo-walk-2023/` 中白桥—亭廊、主路、自行车和湖岸连续照片；
- `recent-2023-2026/qinyuan-student-2026-09-02/` 中从东食堂方向接近勤园，再到下沉球场与扶梯的连续叙述和照片；
- `video-index.md` 中 2025、2026 年的长时校园导览。只有无跳剪片段才能证明沿途顺序。

### C 级：确定外观和气氛

北湖季节、动物、食堂、宿舍、社团活动、雨雪、道路夜景和视频封面都属于这一层。它们很适合提炼颜色、光线、学生密度和笑点，但不能自行决定关卡地图。

## 目录结构

### `recent-2023-2026/`

近期材料是本库的主参考，不再由十年前的校方宣传照主导：

- `commons-2024-2025/`：Wikimedia Commons 的良乡校区照片，部分为 CC BY-SA 4.0；逐文件许可仍应回查原页面。
- `exchange-student-2024-2026/`：不同国家交换生或暑校学生拍摄的道路、北湖、礼堂、教室和食堂。学生视角真实，但没有开放许可。
- `qinyuan-student-2026-09-02/`：勤园当前外部道路、下沉球场、扶梯、公共空间、宿舍和学生地图。
- `campus-updates-2025/`、`new-dorms-2026/`：近期校园更新、国防文化广场和新宿舍组团。
- `north-lake-seasons/`、`winter-2025/`、`student-weather-2025-2026/`：同一校园在秋、冬、雨、雪、昼夜中的变化。
- `daily-life-2025/`、`student-life-articles/`、`events-2025-2026/`：食堂、服务中心、宿舍、社团和人流。混校区或活动拼贴图片已在文件名或来源清单中标注，不能用于推导空间。
- `student-maintained-maps/`：学生维护的总图和文萃楼群图。
- `visitor-photo-walk-2023/`：一条完整照片游记中的 18 张校园照片，适合补充学生高度的观察尺度；2023 年局部状态需被 2025—2026 年资料校正。
- `north-lake-route-2026/`：红桥行走、岸上文化步道、思源榭主仪式区及隔水回望红桥。照片与报道文字共同确认一段真实路线，但不能证明红桥连接两岸。

### `maps/`、`official-photos/`、`third-party-reference/`

这些是第一轮搜集留下的基础材料。旧校方照片仍可用于长期不变的建筑轮廓和历史对照，但在场景细节上服从近期学生视角材料。

旧第三方活动页中的第二张建筑照片曾被误写成“文津楼”。校内已确认的建筑群名称是“文萃楼”，但该照片本身尚不能可靠对应具体楼栋，因此文件已改名为 `2025-venue-building-event-guide.png`，只按“活动场地建筑”处理。

### `video-thumbnails/` 与 `video-index.md`

仓库只保存 2023—2026 年公开视频封面和索引，不下载完整视频，也不把封面当成可发布游戏素材。长时导览用于核对道路连续性，短视频用于观察鹅过路、摆渡车、日落、雪景和学生生活等气氛。

### `source-documents/`

`2025-bit-liangxiang-summer-school-student-report.pdf` 是汉诺威大学公开的学生体验报告。它明确描述宿舍附近的篮球场、北湖、鸭／鹅与羊驼区域，并提供跨校园步行尺度和 2025 年学生视角照片。PDF 没有开放许可，只保留为证据上下文。

## 现阶段可以确认的设计结论

- 良乡东路把北区与南区分开。跨区关卡必须表现道路、北理桥或明确章节转场。
- 北湖北侧是丹枫园／劲松园和篮球区域；西南侧是静园、学生服务与食堂；南侧至东南侧是综教、行政楼和徐特立图书馆；东侧是甘棠园、东食堂和勤园。
- 文萃楼群在教学公共组团以东、文体—国防文化区域以西；文萃是多栋连接建筑，不能被画成单栋通用楼。
- 北湖西侧白桥与中式亭廊属于同一园林组团；北湖红桥从西侧进入湖面中段，是可步行且独立于白桥的结构；水中生态岛与南岸动物区分开；东南岸地图水榭较高置信对应思源榭。
- 体育馆／文体中心与国防文化广场确实相邻，飞机和坦克已经集中到该区域的近期布局优先于旧南区坦克照片。
- 横版画面向右推进只是阅读方向，不等于现实向东。现实路线转弯时，需要用道路转角、桥、门洞、树列变化或章节转场说明。

## 使用边界

- 公开可浏览不等于可自由复制。北理工官网、学生博客、媒体、Bilibili、Meipian、T—Ж、UTS Think Global 和大学公开 PDF 中的图片，除非明确标出开放许可，都只作内部研究。
- 游戏美术应从多来源提炼建筑轮廓、空间关系、季节颜色和生活行为后原创重绘，不直接描图或裁切。
- 有可识别学生正脸的素材不进入可分发版本。
- 用户提供的校园网登录页截图单独保存在上级目录。正式游戏只加载预缩小副本，并明确喜剧化，不能索取、保存或发送账号密码。

## 尚未补齐的结构证据

- 北湖已经确认“西侧 → 红桥湖中段 → 文化步道 → 思源榭”的部分路线；白桥亭廊、动物区与这条路线之间的完整岔路和环湖顺序仍需无跳剪路线核对。
- 文萃／文体中心到国防文化广场的常用地面入口和当前围挡仍需连续行走证据。
- 2026 年交换生照片中的礼堂柱廊已由 Commons 照片和 2025 年学生报告交叉确认；三角采光顶大型室内空间仍未核实正式建筑名称，文件名保持中性。
- 普通校园道路照片很多，但多数没有精确道路名称；不能为了拼关卡擅自把它们接到某栋楼门前。

新增素材如果不能补充“新地点、新视角、新季节、新生活状态或新的空间关系”中的至少一项，就不再机械收集。下一阶段的主要工作是验证路线，而不是继续用数量掩盖结构缺口。
