# 首版关卡空间边界

更新日期：2026-09-03

本文只约束已冻结的第一、二关，不再提出候选章节。

## 第一关：北湖动物借道

真实依据：北湖及周边道路、红桥、湖岸植被和动物生活语境。地图、拓扑与航拍支持红桥至少从西侧岸边进入湖区，近景照片能看到桥面下的立柱／桥墩；当前材料仍不能证明红桥另一端的完整连岸路线，也不能证明完整环湖步行顺序。

允许的改编：压缩道路、增加平台高差、让鹅按玩法需要横穿、把向右滚动作为阅读方向。画面应选择红桥或湖岸道路作为一个主地标，其余元素只作弱背景。

禁止的表达：把白桥、红桥、亭廊、思源榭和动物区拼成同一处并称为真实复刻；让红桥无岸端、无桥墩地浮在水上；把鹅当成固定地理标记；用照片中学生正脸作为正式素材。

第一关的空间卡：

```text
真实区域：北湖组团
入口：普通湖岸道路
主地标：红桥或可识别湖岸，二选一
岸线与支撑：红桥至少一个岸端与主要桥墩可解释；另一端路线保持未知
出口：继续通往校园主路的抽象出口
玩家顺序：学习跑跳 → 遇到鹅群移动边界 → 用绳互相接应 → 双人到达出口
证据等级：整体地图 A；局部同框 B；完整连续路线未知
```

## 第二关：北理桥校园网掉线

真实依据：良乡东路分隔南北区域，北理桥承担跨越道路的校园联系。当前地图支持分区关系，但本地库没有足够的连续桥面照片支持细节复刻。

允许的改编：用一段明确的桥和道路转场表达跨区；压缩桥长；让真实校园网截图作为异常卡片坠入桥面并成为平台。截图的显示和碰撞分离：页面像素保持可辨认，平台性由独立几何体提供。

禁止的表达：声称桥体比例、入口顺序或周边建筑已经精确核对；让桥体没有道路落点或结构支撑；让生成模型重画、改写真实登录页；把页面伪装成可操作的系统／浏览器窗口；要求真实登录。

第二关的空间卡：

```text
真实区域：北区到南区的章节过渡
入口：北区校园道路
主地标：桥与下方道路
出口：南区抽象校园道路
异常事件：校园网卡片坠落并改变平台结构
玩家顺序：进入桥面 → 卡片落下 → 利用卡片和提示横梁 → 双人离开桥面
证据等级：整体地图 A；桥面连续路线和细节未知
```
