# 良乡校区视频与连续路线索引

更新日期：2026-09-03

视频解决照片无法解决的问题：一条路如何连续连接两个地点、转弯发生在哪里、步行尺度有多大、学生在哪些位置停留。仓库只保存公开视频封面，不下载完整视频，也不保存批量截帧。

## 使用规则

- 只有**没有跳剪的连续片段**可以证明沿途顺序；导览视频整体经过剪辑时，镜头先后不等于地理先后。
- 封面只能帮助辨认视频主题，不能证明空间关系。
- MV、混校区表演和活动集锦适合观察气氛，不适合还原路线。
- Bilibili 的“未经作者授权，禁止转载”标记不是唯一版权标准。无论是否显示该标记，只要没有明确开放许可，就不把视频、音轨、封面或截图直接打包进游戏。
- 逐段观察结果应写进 `spatial-structure.md` 或单独的路线记录，不能只停留在观看者记忆中。

## 观看记录模板

每次只记录一个连续片段，并保存以下字段：

```text
视频与时间码：
连续片段起点／终点：
是否存在跳剪：
画面朝向能否确认：
按顺序出现的道路、门、桥和建筑：
学生从哪里停留、转弯或加速：
可转译成横版关卡的高低差与障碍：
仍不能确认的关系：
```

如果时间码、剪辑点和地图无法相互对上，该片段只降级为外观或气氛参考，不进入正式关卡拓扑。
