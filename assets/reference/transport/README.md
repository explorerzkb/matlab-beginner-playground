## 已目视确认的内容

- 两张照片均显示北理工绿白涂装的大巴，车身可见“北京理工大学”和英文校名；
- 第一张提供接近完整的左侧车身视角，适合提炼车身长度、车窗节奏、前后轮位置和大面积绿白分区；
- 第二张提供车辆前部、挡风玻璃、后视镜、车灯和前侧透视，文件元数据将车辆标记为“北理工校车 京AWU969 莲花桥”；
- 照片只能证明拍摄时车辆的外观，不能证明当前车队数量、固定运行线路、精确尺寸或它与游戏交通区域的现实空间关系。

- 游戏校车可参考绿白配色、长途大巴比例、深色连续车窗和双轴轮位，但不得直接复制真实车牌、乘客面孔或照片背景；
- 若只将照片作为内部重绘参考，正式成品应保持原创表达；若直接使用或改作 Commons 照片，发布时必须保留完整的 CC BY-SA 4.0 署名记录；
- 在校车正式进入运行时前，按 `docs/visual-spatial-sop.md` 新建视觉检查记录，并重新核对隐私、授权、车辆可读性和碰撞边界。
