## 光影推断规则与结论边界

用户明确允许根据光影结构推测。用屋檐/柱子的投影、立面明暗、反射与透视消失方向联合判断，而不是仅凭“暗面朝北”。深檐可使向阳面落在自身阴影中，夜景人工照明不能当太阳方向，玻璃明亮可能是反射。先以带方向标注的西、北立面固定体育馆形体；未标方位的文博照片需继续结合校园地图、建筑转角及背景楼匹配，当前不把阴影单独推成确证的西立面。
