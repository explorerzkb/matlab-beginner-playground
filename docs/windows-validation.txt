这是 Windows 待验收包，不是已通过 Windows 实测的最终版。
解压后，在 MATLAB 中打开本文件所在文件夹，运行 startGame。也可以双击 startGame.bat；找不到 MATLAB 时，请用前一种方法。
玩家一用 A/D/W，玩家二用方向键；备用键位是 J/L/I。Esc 暂停，按住 R 0.8 秒回到检查点，Q 退出。
一键检查：双击 validateWindows.bat，选择当前 100%/125%/150% 显示缩放。它会运行代码、机制、序章、四条输入路线、50 Hz 完整屏幕刷新节拍、连续三轮五场景最大绘制能力，再引导两人检查六组真实四键／五键组合。结果保存在 windows-validation-results 文件夹。
可选高画质性能检查：在 MATLAB 中运行 addpath('tests'); runPerformanceCheck(false)，对应 1280x720 窗口和背景 2 像素采样。它不改动默认档。
真人整局：在 MATLAB 中运行 runWindowsPlaytest。按提示记录缩放、计划路线、玩家二键位和本局编号；窗口标题显示实际 FPS，退出后由两人确认画面可读性和操作响应。每段至少停留 2 秒且严格高于 40 FPS 才算有效样本。
完成若干局后运行 summarizeWindowsValidation。只有 100%/125%/150% 三档自动检查与整局记录、至少三局、上桥/下路、方向键/JLI、两人画面与操作确认全部齐全，汇总才显示 PASS。
请在三种缩放比下各检查画面，并用两名真人连续完成三局，覆盖上桥和下路、主键位和备用键位。自动检查通过仍不能替代这部分。
