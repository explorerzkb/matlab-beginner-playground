## 2. 角色、输入与普通绳

- 玩家一：`A`、`D`移动，`W`跳跃；
- 玩家二：方向键移动与跳跃，备用为 `J`、`L`、`I`；
- `Space`长按饮用共享背包中的冰红茶；`Esc`暂停，长按 `R`回检查点，`Q`退出；
- 两只梨同体型、同质量、同碰撞盒和同基础能力，不加腿、叶片、胸前圆形或菱形徽章；
- 绳松弛时不施力，拉紧后只传递有上限的拉力；不缠绕、不打结、不断裂，也不主动伸缩。

角色视觉使用高密度程序曲线身体与代码驱动表情。玩家一为库尔勒香梨式黄绿色，玩家二为温暖奶油白的鸭梨艺术变体。轮廓真实像梨、上窄下圆、描边细且柔和；短棕色果柄在碰撞盒外。

身体采用极轻微的左上亮、右下暗塑形，整体明暗差约 5%；少量表面浅坑、细点和不均匀色斑在正常尺寸下约 1—2 像素、明暗差不超过约 3%。纹理固定在身体局部坐标中，不逐帧随机，不形成塑料高光、黑斑或麻面。表情覆盖行走、跳跃、下落、绳索吃力、受击、攀爬和撞灯眩晕。

## 3. 三颗共享爱心与冰红茶

旧 `破防值 0/6` 完全删除，改为三颗共享爱心：

- 开局和检查点复活均为三颗满心；
- 动物主动冲撞扣一颗心，并给予 `0.85 秒`受击无敌；
- 行驶中的公路车辆和坠入深渊清空三颗心；
- 爱心归零后播放约 `0.45 秒`反馈（校园网超时死亡为 `5 秒`），两人回到最近检查点并恢复三颗心；
- 自行车剧情撞飞、羊驼踢飞、孔雀弹射、普通推挤、攀爬失败和撞路灯不扣血。

冰红茶与血量完全隔离，不回血、不减伤、不延长受击无敌：

- 共享背包最多两瓶；北湖入口连续放置三瓶，背包满时第三瓶留在世界中；

HUD 是独立屏幕覆盖层，不随镜头移动：三颗 8×7 像素心、两个真实冰红茶像素图标、重生次数、六格绳力条和简短地区名。梨子本身保持平滑，不像素化。
