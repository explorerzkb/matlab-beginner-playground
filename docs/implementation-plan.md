# 连续校园世界第二轮实现计划

更新日期：2026-09-04

本文把 `game-spec-v1.md` 当前的 v2 内容转换成实施顺序。玩家只看到一张连续地图；代码内部保留区域文件和阶段门。每个可独立观察、验证和撤销的功能必须单独提交。

## 1. 最小架构

```text
startGame
  → runGame：一个会话、一个世界状态、一个结果页
      → stepPhysics：输入、重力、碰撞、普通绳
      → stepConsumables：冰红茶拾取、饮用和强化
      → stepContinuousWorld：检查点、破防值和区域调度
          → 北湖动物
          → 校园网页面
          → 南北交通
          → 乐学任务
      → renderFrame：连续摄像机和当前区域反馈
```

不建立通用实体组件系统。只抽取移动平台、冲量区域、双人保持区和阶段时钟四种小型复用能力；复杂行为仍留在按校园语义命名的区域函数中。

## 2. 连续世界数据

世界只创建一次，包含全局宽度、静态平台、区域范围、检查点、出生点和最终出口。四个区域数据文件继续独立编写，由一个构建函数赋予全局横坐标并拼接。

`state` 持续保存玩家、绳、连续轨迹、破防值、共享冰红茶、强化计时、已拾取道具、当前检查点、交通路线和区域事件。进入新区域不得重新调用角色初始化。

只更新镜头附近及相邻区域的动态对象。校园网和乐学所需图片或结构在进入主循环前准备，游戏循环中不读盘、不联网。

## 3. 实施阶段门

### 阶段 A：首轮版本管理补救

把现有首轮工作按配置、启动、输入、物理、绳力、检查点、各关机制、渲染、声音、测试和文档拆成原子提交。使用 `explorerzkb@gmail.com`，完整验证后再推送；远程隐私策略阻挡时保留本地历史并如实记录，不改用其他邮箱绕过。

### 阶段 B：连续运行骨架

交付单一世界构建、连续状态、区域调度和无关卡卡片的主循环。最低验证是测试模式只初始化一次玩家状态，能从起点推进到最终出口，轨迹时间单调且不中断。

### 阶段 C：检查点、破防值与冰红茶

先实现当前破防值与累计失败分离，再实现轻重失败、共同复活、检查点快照、冰红茶拾取、`Space`饮用和六秒强化。最低验证包括不刷道具、不倒扣失败历史、强化结束后参数恢复，以及复活后绳和速度干净。

### 阶段 D：校园交互区域

按北湖动物、校园网页面、交通岔路、乐学任务的顺序接入。每个机关完成后单独提交并增加直接测试。

- 北湖：鹅群阻挡，羊驼助推是可选捷径；
- 校园网：输入区双人保持、按钮共同触发、复选框检查点、充值弹板和自助服务升降台；
- 交通：喷泉上桥、桥面绳力合作、红绿灯相位、车辆和软人群；
- 乐学：倒计时平台、共同开始选课、课程卡、通知任务、破防水和 Lucy 河。

### 阶段 E：验证与记录

运行代码分析、输入、物理、区域状态、两条交通路线、连续生命周期、十分钟等价步进、隐私扫描和性能测试。Mac 结果只作为开发证据；Windows 多键冲突、缩放、连续三局和最终时长仍需目标机实测。

### 阶段 F：第三轮试玩返工

用户真实试玩否定了“车流可通过”“羊驼价值足够”和“页面结构近似即可”三个旧判断。按以下顺序返工，每项独立提交：

1. 为红绿灯增加安全等待区、全红清空、行人开放入口和只在行驶危险区生效的车撞判定；新增双人从等待区到对岸的端到端物理测试；
2. 延长北湖动物段并增加鸭群，使动物路线至少覆盖两个完整镜头宽度；
3. 把羊驼喷嚏连接到有明确落点的高层红桥捷径，测试喷嚏确实能绕过后半段地面路线；
4. 为校园网原图和两张乐学截图建立像素坐标表与统一等比例映射函数；
5. 校园网直接显示完整原图，交互矩形只覆盖原控件位置；乐学以同位置脱敏重绘保留原始栅格，不移动任何核心控件；
6. 重新生成交通、北湖、校园网、乐学截图并逐张与原参考对照。旧的第二轮“机制画面通过”结论不再作为当前验收依据。

## 4. 提交和验证规则

- 只暂存本功能涉及的明确文件或代码块，不使用 `git add .`；
- 提交前执行 `git diff --cached --check` 并阅读完整暂存差异；
- 逻辑功能必须有直接断言，画面功能必须实际生成并打开截图；
- 交通测试必须包含完整通行轨迹，页面测试必须断言控件像素框经过同一变换后的世界坐标；
- 一个提交失败时就在下一个独立 `fix` 提交中说明和修复，不把无关改动塞入；
- 合并时保留功能提交，不执行 Squash；
- 每次推送后核验远程作者、邮箱和默认分支归属。

## 5. 明确不要优化

- 第二轮不精修背景、角色、材质、粒子和音效；
- 不复制含个人信息的乐学截图；
- 不实现真实登录、选课、外部链接或校园网络请求；
- 不增加战斗、写实死亡、复杂背包、商店或跨局存档；
- 不改变普通绳为柔性绳，也不让强化修改绳长和碰撞体；
- 不把内部区域重新表现成玩家可见的硬关卡。
