# 关卡场景空间卡模板

每一段正式关卡在进入美术制作和 MATLAB 编码前，都要复制并填写一张空间卡。空间卡的作用是把真实校园结构与游戏改编边界写清楚，避免开发过程中又把几张独立照片拼成不存在的空间。

```text
场景卡编号：
状态：候选／结构已核对／可进入灰盒／已冻结

真实区域：
现实地图方位：
游戏画面推进方向：
说明：游戏向右是否对应现实东向；若不对应，在哪里表现转弯

入口：
出口：
主地标：
最多一个辅助识别地标：
相邻但不应进入本屏的地点：
明确不相邻、禁止硬拼的地点：

玩家按顺序经过：
1.
2.
3.

地图证据：
同框照片证据：
连续路线证据与时间码：
当前证据等级：A 地图／B 同框或连续路线／C 单景外观

允许压缩的现实距离：
允许增加的游戏高低差：
允许的异常空间事件：
不得改变的邻接或先后关系：

双人绳索在本段承担的玩法：
两名玩家分别持续要做什么：
首次观看者如何在不读说明的情况下看懂：

仍未确认的问题：
需要当前良乡学生复核的内容：
```

空间卡通过的最低条件是：真实区域、入口、出口、主地标、相邻关系和证据都有明确答案；无法确认的内容被写成未知，而不是由设计者猜测补齐。视觉风格、平台高度和笑点可以继续迭代，但真实校园关系发生变化时，必须同步更新空间卡及来源记录。
