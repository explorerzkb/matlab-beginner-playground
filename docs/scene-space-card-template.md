# 关卡场景空间卡模板

当未来新增或重做现实校园场景时，在美术制作前复制并填写一张空间卡。首版第一、二关已经在 `assets/reference/liangxiang/spatial-structure.md` 填写，第三、四关属于明确的象征空间，不需要伪造现实邻接。

```text
[ ] 未知关系没有被画成已确认事实
```

空间卡通过的最低条件是：真实区域、入口、出口、主地标、相邻关系、落点／支撑和证据都有明确答案；索引指定的图片已经被实际打开；无法确认的内容被写成未知，而不是由设计者猜测补齐。视觉风格、平台高度和笑点可以继续迭代，但真实校园关系发生变化时，必须同步更新空间卡及来源记录。完整复核规则见 [`visual-spatial-sop.md`](visual-spatial-sop.md)。
