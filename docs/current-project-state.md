## 当前冻结玩法

- 两名玩家共用键盘，控制同体型、同能力、同碰撞体的无腿无叶小梨；
- 两人由松弛时不施力、绷紧后产生拉力的普通绳连接；
- 一张连续横向地图从 MATLAB 坐标轴推进到 Lucy 河，不显示关卡卡片或逐段清空状态；
- 北湖包含鹅群阻挡和可选羊驼助推；
- 校园网完整页面成为可攀爬、可按压的物理空间；
- 南北交通允许喷泉／北理桥和红绿灯两条真实可行路线；
- 乐学区域包含倒计时平台、共同开始选课、通知任务和最终冲刺；
- 当前破防值与累计失败分开，冰红茶可降低破防值并短时强化两名玩家；
- 只做单局检查点，不做磁盘存档、写实死亡、战斗、真实登录或联网服务。

详细行为以 [`game-spec-v1.md`](game-spec-v1.md) 当前 v2 内容为准。
