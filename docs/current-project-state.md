## 已冻结范围

- 二维横向平台游戏，两名玩家共用一把键盘；
- 两只同体型、同能力的小梨角色，由一根松弛时不施力、拉直后传递拉力的普通绳连接；
- 两只梨不画永久可见的腿，不加叶子或叶柄；用梨身倾斜、挤压、弹跳、阴影和表情变化表现运动，避免额外的人形步态系统；
- 自由左右移动和跳跃，不采用强制自动前进；
- 序章之后依次完成四关：北湖动物、北理桥校园网、艾比特导航故障、期末任务风暴与破防水；
- `Lucy 河`是最后一关的终点仪式，结算把本局真实轨迹重新画成 MATLAB 曲线；
- 没有怪物、战斗、生命值和角色死亡；失败后整对玩家回到本关检查点；
- 视觉采用“校园漫画平涂 + MATLAB 图形语言”，不再继续比较旧画风预览；
- 核心运行环境为基础 MATLAB R2025b，Windows 11 是最终验收平台；
- 游戏离线运行，不连接 `10.0.0.55`，不采集账号密码，不依赖云端服务。
- 第二关直接显示经过隐私检查的真实校园网登录页截图，不由生成模型或 MATLAB 图元重画；MATLAB 只把它作为图片移动和显示，碰撞数据独立存在。
- 所有画面、场景和建模任务执行 `visual-spatial-sop.md`，必须实际打开参考图并验证桥端、支撑、岸线和前后景关系。

完整行为和每关职责见 [`game-spec-v1.md`](game-spec-v1.md)。

以下不是继续写方案才能回答的问题，应通过原型和实机测试解决：

1. 普通绳的长度、最大拉力和阻尼取值怎样才能既可控又能产生合作笑点；

5. 四关总时长是否落在约 4—6 分钟，课堂展示是否需要提供短演示模式。

这些项目只能记录为“待验证”，不能在运行前写成已经通过。
