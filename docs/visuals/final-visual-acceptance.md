## 结论

最终视觉阶段已经在开发机 MATLAB R2025b 中实现。16 张最终运行时截图均由当前代码确定性生成并逐张打开检查，不是设计稿代替实机画面。画面已经从灰底原型升级为有空气透视、植被／水体／建筑材质、前中远景层次和校园识别锚点的手绘场景。

- 北湖西段使用实际打开的北湖地图／工作拓扑、红桥落点照片和航空视角；运行时红桥有可见岸端与支撑。东段回到开阔水面和树列，不凭空延长红桥。
- 体育馆、坦克与飞机使用文体中心和公开教育展示照片，只表达校园体育与国防教育展示语义，不表达战斗，也不证明装备与建筑的精确现实距离。
- 文博馆使用官方外观和室内参观参考，只证明建筑外观与文化空间属性。它与体育馆在横向关卡中相邻属于章节编排，不是现实邻接结论。
- 校徽来自学校官方视觉识别规范页的本地裁切，不由生成模型重画。
- 两张含个人信息的乐学截图只保存在 Git 忽略目录，运行时页面是原位置脱敏重建；没有把私有截图交给图像生成服务。

## 页面、HUD 与暂停层

- 校园网继续使用完整运行时截图作为主体；用户名、密码、记住密码、登录、自助服务和充值区仍由同一页面像素变换得到。
- 乐学选课页和首页仍分别使用 2852×1654 原图的统一像素坐标系；背景优化没有移动内部标题、倒计时、用户卡、开始按钮、教程、通知和课程卡。
- `ui-ux-pro-max` 只辅助检查 HUD、按键提示、暂停层、信息层级和颜色可读性。最终 HUD 使用深色高对比状态条、独立指令条、右侧检查点与固定按键提示；暂停时用暗化遮罩和居中浅色卡片，不改变场景与角色设计。
