# v23 图片缓存、启动与最终包复核

本轮针对启动和场景初始化继续优化，没有修改默认或高画质档的分辨率与采样标准。剖析发现，可控的主要启动成本是同一批静态 PNG 被重复读取、再重复降采样；现在由 `readGameImage` 复用“指定步长下已经采样好的图”，并以路径、采样步长、文件修改时间和字节数作为缓存键与失效依据。缓存只在当前 MATLAB 进程内生效。

相同进程的改前两次测试启动为 4.427 / 1.026 秒，最终采样缓存版三次为 4.353 / 0.793 / 0.700 秒。第二次启动约快 22.7%，冷启动没有可测退化。新增 `testGameImageCache` 检查步长后的尺寸、重复读取一致性，以及覆盖原文件后的自动失效。

最终工作树统一验收通过：Code Analyzer 零问题，烟雾测试、连续序章和四条完整输入旅程全部通过；五段强制绘制为 81.4 / 107.8 / 80.0 / 98.4 / 151.1 FPS，最低 80.0 FPS；默认档和 1280×720 高画质档五段定速刷新均为 49.6 FPS。
