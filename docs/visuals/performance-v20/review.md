# v20 性能复核

本轮没有继续降低画质，而是把计划绘制从 45 Hz 提到 50 Hz，为“实际帧率高于 40”留出更明显的余量。默认档仍是 960×540、普通背景步长 6；高画质档仍是 1280×720、背景步长 2；物理和输入保持 60 Hz。

当前工作树完整统一回归通过：Code Analyzer 零问题，烟雾测试、连续序章和四条输入旅程全部通过。五段强制绘制为 71.6 / 92.1 / 69.1 / 82.9 / 132.3 FPS，最低 69.1 FPS；50 Hz 定速完整刷新为 49.9 / 50.0 / 50.0 / 50.0 / 50.0 FPS，最低 49.9 FPS，见 `latest-run.txt`。

单独复测默认档和高画质档时，默认档最低 48.5 FPS，高画质档最低 49.8 FPS，见 `paced-default-high-quality.txt`。真正的 `startGame('ValidationMode', true)` 主循环在北湖累计 8.9 秒、445 帧，为 49.7 FPS，见 `interactive-main-loop.txt`。

复核过程中发现并停止了一个已卡住 53 分钟、持续占满一个 CPU 核的旧 MATLAB 验收进程；未停止另一个与本项目无关的满核 Node 服务。清理后再次测得默认档最低 48.8 FPS、高画质档五段均为 50.0 FPS，见 `paced-after-stale-cleanup.txt`。本轮没有改画面内容；重新打开了高画质北湖动物和校车路灯两张运行图，HUD、角色、湖面、桥梁、建筑、车辆与路灯仍清楚可辨。

这些数据来自 Apple Silicon Mac、MATLAB R2025b。目标 Windows 11 的两名真人、六组多键组合、100%／125%／150% 缩放和连续三局仍需执行，不能由本页替代。

最终 Windows 待验收包在全新临时目录解压后也通过统一回归：强制绘制五段为 71.3 / 91.8 / 69.5 / 82.6 / 134.6 FPS，最低 69.5 FPS；默认档 50 Hz 定速最低 49.8 FPS，高画质档最低 49.6 FPS。包内 131 个项目文件与当前工作树逐一一致，ZIP 共 132 项、27,270,060 字节，SHA-256 为 `c1bcd42c5b65698e21cc5d7517d95cb35f162433edc3bfe2b1faaa27ab8a4881`。
