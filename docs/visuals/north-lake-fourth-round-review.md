## 本轮实现

### 可玩空间和阻挡语义

- 鹅鸭接触只施加有上限的水平软推力，目标速度 `3.0`，低于玩家最大奔跑速度；玩家可等待、跳过或顶着穿过。
- 鹅鸭仍保留移动范围、速度差和朝向，但其矩形只用于软推检测，不再加入通用刚性碰撞体。
- 高桥从 `y = 4.8` 抬到 `y = 6.5`，桥底到地面净空为 `5.5` 世界单位，大于两倍角色高度 `2.9`。
- 羊驼视觉顶端约为 `y = 4.93`，到桥底仍有约 `1.57` 世界单位，超过一个角色高度；首根支撑同时右移，避免产生新的封闭小口袋。
- 喷嚏冲量提高为 `[9.0, 23.0]`。自动测试不是只查数值，而是在同伴位于左侧、绳产生反向牵引的条件下，模拟角色从鼻部起飞并实际落到高桥。

### 动物造型

- 羊驼使用独立 PNG 精灵：暖象牙白和浅驼阴影、蓬松毛束、长颈、直耳、短尾、四肢与深色蹄部均可辨认。
- 最终羊驼眼睛比第一版明显缩小，改为侧向目光、轻微挑眉和不对称嘴角；在运行时缩放后保留“欠欠但可爱”，不再由大眼主导脸部。
- 图像生成器连续两次把棋盘格画进 RGB 背景，均未直接采用。最终选择造型正确的一版，只对从画布边缘连通的近白背景生成透明通道；对蓝色底合成检查后，没有发现羊毛内部被挖空。
- 鹅和鸭仍用 MATLAB 图形绘制，但从椭圆加线条的占位符升级为分层身体、颈／头、喙、翅膀、眼睛、腿脚和阴影，并随运动方向翻转。
