# 最终美术资产生成与使用说明

更新日期：2026-09-04

## 目标与分工

附件质量参考仅用于确认手绘游戏美术的质感：柔和但清晰的轮廓、分层自然景观、材质纹理、空气透视和可读前景。它不用于推导北湖、建筑、桥梁、岸线或平台空间。

四张生成背景只承担非碰撞美术层，玩家碰撞、通道、桥端、平台、网页控件和物理空间仍由代码与当前规格决定。

生成提示的共同约束：

- 16:9 侧视游戏背景，低层区域留给代码绘制的玩家通道；
- 质感参考只用于高层美术质量，严禁复制其桥、岛、悬台、建筑、地形或空间关系；
- 无玩家、无界面、无文字、无校徽、无坐标网格和无游戏平台；
- 不允许浮空建筑或缺少支撑的桥梁。

生成结果仍需通过实际 MATLAB 截图确认是否与代码层、主角和页面主体匹配。未经截图复核，不能称为最终效果。
