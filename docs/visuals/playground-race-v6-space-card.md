# 操场衔接与八道短跑空间卡（2026-09-09）

已实际打开校园地图、校园结构工作图、原始校园网登录页、用户北理桥照片及本轮实玩截图。地图证明操场与道路的校园语境，不证明横版路线和精确距离。登录页照片证明饱和蓝天、低树线、草坪、砖红塑胶和平行白线的颜色与透视；桥照片证明道路与桥墩，不证明操场紧邻桥。照片缺乏近景跑者尺度，跑者按现有梨的约 1.45 世界单位身高设计，属于玩法尺度。

入口：固定网页右缘 x≈82.92，保持整页不移动、不淡化；向右进入同色照片质感操场。出口：x112 的道路与北理桥。操场上方是低树线、草坪与天空，下方是砖红八道跑道，沿横向视角排列，不使用绿色底加红色横条。地面与碰撞顶面 y1 对齐；以页内跑道 y约1.2–2.3 为衔接标高。比赛起点 x90，终点 x108，八名学生是背景比赛层，不阻挡两只梨，不产生空气墙。

两梨都到起点后同时发令。固定对手速度略低于普通梨，目标普通不间断跑在终点领先约半个身位；冰红茶使用真实背包与增益，不给对手自适应追赶。停下或回头允许输，比赛不锁后续通路；结果记录两梨分别到达时间，复位到起点前可重赛。八名跑者各占一条可辨认跑道。
