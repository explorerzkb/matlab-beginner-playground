# 小路与车辆伤害修订（2026-09-09）

用户明确补充：文博和体育馆之间是一条约 3 米宽的小路，两侧草坪。此宽度指横断面，不缩短两建筑的横向游戏距离。当前绘制在 190–240 范围用草坪、窄路、草坪三层覆盖旧宽路；3 米深度按 0.5 投影比例显示为 1.5 单位。延用本任务已经逐张打开过的校园地图、文博/体育馆照片与 open-plaza-v5.png 的像素纹理，不新增未经确认的现实物件。低矮草坪不承担竖直障碍碰撞，角色脚底与路面前沿 y=1 一致。

公交车过去只有车顶单向承托，没有车身伤害。现在车身扣 3 点共享生命，屋顶保留可乘坐；车体以伤害处理而非把角色挤入地面。复活点 7 移到 x186.2/187.7，位于车辆循环起点 x190 之前。

北理桥汽车过去同时要求汽车和梨在斑马线中才伤害；现按实际车身及每帧扫过的范围判断，不受上桥/地面路线选择或斑马线边界豁免。实际桥面高度不与汽车相交。红灯停住的车不主动撞人，行驶阶段碰撞仍按原规格致命。

自行车 3 辆改为 9 辆，速度从约 8–10 提高到 18–22；双向外形镜像、短速度线；撞飞后车流继续离开，不再定格。保留 0.9 秒预警和按实际高度计算的安全落地，保持剧情不扣血。

测试须分别证明公交车 3 点、屋顶安全、斑马线外汽车伤害、桥面安全、复活不连死与完整通关。旧测试“公交车区域无论碰撞都不能扣血”已被新需求撤销，恢复测试改为检查确实受伤并安全复位。

## 本轮结果与限制

Code Analyzer、车辆伤害、复位恢复和四条真实输入路线通过。每条路线有一次公交碰撞后恢复，第四条另有一次北湖失误；基准测试由旧的绝对无伤改为新危险规则下有界重试，未修改生命数或关闭伤害来通过。复活点 7 在 x186 提前领取，复活时公交循环重新从起点开始。
