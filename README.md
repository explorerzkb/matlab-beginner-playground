# MATLAB Beginner Playground

一组面向 MATLAB 初学者的轻量小游戏与练习，用来边玩边熟悉变量、数组、条件判断、循环、函数和绘图。

项目仍在起步阶段，玩法和目录结构会随着学习逐步调整。

当前首先阅读[游戏方案默认假设审计 01](docs/assumption-audit-01.md)。该文档区分已经确认的要求、仍未成立的高影响假设、只能靠原型回答的问题和旧文档冲突；生产任务计划在审计完成前暂停。

已确认的目标、约束和北理工校园素材记录在 [项目简报](docs/project-brief.md) 中。[良乡校区视觉与空间参考库](assets/reference/liangxiang/README.md)保存地图、2023—2026 年学生视角照片、视频索引和来源登记；[校园空间结构与关卡转译约束](assets/reference/liangxiang/spatial-structure.md)进一步区分已经确认的方位／邻接、只能参考外观的材料和仍需连续路线核对的缺口。每一段正式关卡在美术和编码前都要填写[关卡场景空间卡](docs/scene-space-card-template.md)。当前推荐的原创双人角色方向见[双人角色方向 01：从 MATLAB 数据点长成的“梨点”](docs/character-direction-01.md)，但角色造型尚未由用户确认。

尚未收敛的校园文化调查与候选脑洞记录在 [良乡校园文化调查与失控创意账本](docs/bit-liangxiang-culture-and-wild-ideas.md) 中；从“有趣”筛到“近期、共同认可、一眼就懂”的第一次范围收缩记录在 [选题第一轮收敛](docs/concept-convergence-01.md) 中。[游戏产品方案 v0.1](docs/game-proposal-v0.1.md) 和 [设计理由与第一次自我审查](docs/design-rationale-v0.1.md) 是早期弹性连接方案的历史基线，不代表当前玩法。[叙事优先，交互为体验服务](docs/narrative-first-core.md)仍是候选叙事，其旧版开场接受过 [第一次模拟盲观众审查](docs/blind-audience-review-01.md)，但不能为新的力场方案背书；[被纠正的界面即世界提案](docs/interface-as-world-design.md)只保留为方向变化记录。项目协作与语言规则见 [AGENTS.md](AGENTS.md)。
