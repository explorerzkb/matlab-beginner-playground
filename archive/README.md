# 历史区

本目录只保存已经失去当前决策权的项目快照。它不是知识库入口，也不是实现规格。

## 强制规则

- 默认不要读取、搜索、总结或引用本目录内容。
- 本目录中的关卡、参数、画风、目录建议和状态即使写得更详细，也全部视为历史信息。
- 只有用户明确要求追溯某项决定，或当前有效文档点名某个历史文件时，才打开那个具体文件。
- 不维护历史文件内部链接，也不根据当前项目变化修改旧快照。
- 任何需要重新启用的旧想法，必须由用户确认后重新写入 `docs/game-spec-v1.md`，不能直接从这里恢复。
