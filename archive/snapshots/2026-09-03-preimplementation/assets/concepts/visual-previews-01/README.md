## 共用生成提示

- 输出十六比九的实际二维横向平台游戏截图，而不是海报、概念图、斜俯视或三维画面。
- 镜头从侧面跟随两个同等重要、能力相同的非人形角色，并在前进方向保留空间。
- 两个角色分别使用梨黄色和湖蓝色；用普通深色绳连接。绳在这一帧被拉直，不打结、不缠绕、不断裂，也不表现成弹簧。
- 右侧角色在高平台站稳并主动拉拽；左侧角色刚从缺口边缘滑落。动作必须读成合作救援，不能像牵宠物。
- 前景平台、缺口和可行路线必须在一秒内看清。
- 背景参考北京理工大学良乡校区的湖、低矮步行桥、绿化、鹅和现代低层校园建筑；排除欧美钟楼、城堡和通用美国大学。
- 将 `assets/reference/bit-campus-network-login-2026.png` 作为辅助插入素材，以小型刚性卡片形式从右上方落入关卡。尽量保留原图的像素、文字、校徽、色彩、比例和排版，不重做登录界面。
- 登录页只能出现在游戏画布内部；角色和平台始终可见。不得出现浏览器边框、Windows 任务栏、真实凭据输入或网络连接暗示。
- 界面只保留 `03:00` 计时和两名玩家的对称状态提示。
- 排除怪物、武器、战斗、死亡、写实人物、牵引意象、炫光手游菜单、赛博朋克、大量粒子、标题和水印。
- 画面应当能由 MATLAB 用少量二维图层、简单形状和有限特效近似实现。

## 五个风格变量

1. 平涂网页游戏：明亮而克制的蓝绿校园色，圆润几何形，适量深色描边，三至四层视差，友好但不幼儿化。
2. MATLAB 绘图世界：暖白科学绘图画布，平台隐约借用坐标轴、网格、曲线和数据标记；不显示代码或密集公式。
3. 校园漫画：自信、干净的手绘线条，有限平涂色和少量纸张纹理；动作线克制，碰撞面仍保持规则清楚。
4. 现代像素：清晰的高分辨率像素块、易读的角色精灵和平台瓦片；真实网页卡片故意保持高分辨率，形成异质笑点。
5. 剪纸拼贴：简化的校园纸片层、轻微纸张纹理和柔和接触阴影；真实网页作为清晰的现成物掉进关卡，不允许画面变成混乱照片拼贴。

## 当前已观察到的偏差

- 五张图都正确回到了二维横向平台游戏，但生成背景只能说明“良乡校园气质”，不能视为真实地标复刻。
- 登录页原图的整体辨识度较好，小字仍发生了生成式重绘；正式游戏必须直接显示原始截图的缩小副本，不能使用预览图中被模型重绘的页面。
- 登录页在五张预览中占屏偏大。正式事件应先确保两名角色、绳和逃生路线仍然清楚，再决定遮挡比例。
- 第三张的绳在黄色角色附近出现了多余线段；这不是确认的绳机制。正式游戏只保留角色之间的一条绳。
- 第五张状态栏将角色画成近似小熊。这只是生成模型的临时造型，不是最终角色设定。
